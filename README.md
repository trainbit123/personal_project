A production-grade, zero-dependency personal tracking web application built to guide daily preparation across **300 DSA Problems**, **Core CSE Subjects**, and **Modern AI Projects** for top product companies (Amazon, Google, Microsoft, Flipkart).

---

## 🌟 Key Features

### 1. 300 DSA Problem Sheet
- **Complete Sheet**: Exactly 300 problems extracted from the PDF across 38 pattern categories and 10 scheduled weeks.
- **Pattern Tips**: Actionable algorithmic tips for every topic (e.g., *Prefix/suffix tricks, in-place swaps, Kadane, cyclic placement*).
- **Direct Solve Links**: Direct one-click links to **LeetCode**, **InterviewBit**, and **GeeksforGeeks**.
- **Real-time Filters & Search**: Search by name, company tags (`Amazon`, `Google`, `Microsoft`, `Flipkart`), difficulty (`Easy`, `Medium`, `Hard`), and week (`1` to `10`).
- **Problem Notes & Complexity Modal**: Record your intuition, time complexity \(O(N)\), space complexity, and flag struggled problems for weekly redo.

### 2. 12-Week Master Roadmap
- **Week 1 - 10**: Problem distribution matching the PDF curriculum (#1-#30, #31-#60, ..., #271-#300).
- **Week 11**: Revision week with timed company sets.
- **Week 12**: Mock interview simulations, core subjects, and behavioral preparation.

### 3. Company Revision Sets (Weeks 11-12)
- Dedicated revision checklists for **Amazon (19 problems)**, **Google (15 problems)**, **Microsoft (18 problems)**, and **Flipkart (14 problems)**.
- Final pre-interview checklist (timed re-solving under 25 minutes, behavioral stories, and system design readiness).

### 4. Core CSE Subjects Hub
- **Operating Systems**: Processes, Threads, CPU Scheduling, Deadlocks & Synchronization, Virtual Memory, TLB, Inodes.
- **DBMS**: Relational Algebra, Normalization (1NF to BCNF), B+ Tree Indexing, Transactions (ACID), Concurrency & MVCC.
- **Computer Networks**: OSI & TCP/IP, TCP 3-Way Handshake, HTTP/1.1 vs HTTP/2 vs HTTP/3 (QUIC), DNS, WebSockets.
- **OOP & Design Patterns**: 4 Pillars, SOLID Principles, GoF patterns (Factory, Singleton, Observer, Strategy).
- **System Design (HLD & LLD)**: Scalability, Caching (Redis), Kafka, DB Sharding, Rate Limiter, Parking Lot, URL Shortener.
- Interactive topic checkboxes and high-yield technical interview Q&A with collapsible answers.

### 5. High-Impact AI Resume Projects (2025/2026 Tier)
Designed specifically to stand out on engineering resumes with deep technical architectures:
1. **Autonomous Multi-Agent DevOps & SRE Incident Remediation Engine** (*LangGraph, Docker SDK, FastAPI, OpenTelemetry*)
2. **Enterprise Multimodal GraphRAG Knowledge & Citation Platform** (*Neo4j, Qdrant, LlamaIndex, BGE-Reranker*)
3. **Ultra-Low Latency Full-Duplex Multimodal AI Copilot** (*WebRTC, LiveKit, Silero VAD, Cartesia TTS, Deepgram STT*)
4. **Autonomous AI Code Reviewer & Semantic Vulnerability Patcher** (*Tree-sitter AST, Semgrep, Docker, GitHub Apps*)
5. **Offline-First Edge LLM Studio with WebGPU & Speculative Decoding** (*WebGPU, WebLLM, OPFS, Wasm, Transformers.js*)

- **Blueprints include**: Full architecture diagram descriptions, 5-week step-by-step milestones, ready-to-paste **STAR-format resume bullets** with 1-click copy, and common interviewer questions & trade-offs.

### 6. Focus Timer & Daily Routine
- **Presets**: 25 Min (Standard), 30 Min (Deep), 40 Min (Hard Cutoff), 45 Min (Mock Interview).
- **Web Audio Chime**: Synthesized audio alert upon completion without external audio dependencies.
- **Streak Tracking**: Automatically records continuous study days.

### 7. Backup & Restore
- 1-click **Export Backup** to save all progress, notes, and milestones as a JSON file.
- **Import Restore** to restore your data on any device or browser.

## 🚀 Running the Web App

### Option A: Local HTTP Server (Already Running)
The app is live locally at:
```
http://localhost:8080
```

To run it again anytime, execute:
```powershell
python -m http.server 8080
```
Or with Node.js:
```powershell
npx serve -l 8080
```

### Option B: Standalone Browser
You can open `index.html` directly in Google Chrome, Microsoft Edge, or Firefox.
